# 영웅입지전 모드매니저

영웅입지전(Legend of Heroes) 모드를 한 창에서 켜고 끄고, 순서를 정하고, 설치·삭제하는 관리 프로그램입니다.

## 받기
오른쪽 **Releases** 에서 가장 위(최신) 판의 zip 을 받아 압축을 풀고 `모드관리.exe` 를 실행하세요.

## 업데이트
0.12.0 부터는 관리창이 새 판을 스스로 확인합니다. 새 판이 있으면 위쪽에 알림이 뜨고, **지금 업데이트** 를 누르면 받아서 바꿔 줍니다.
